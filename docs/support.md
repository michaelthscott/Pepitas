# Pepitas Support

For help with Pepitas, or to report a problem, email [CONTACT EMAIL].

## Common questions

**Translation says to add a DeepL API key.**
Automatic translation needs your own DeepL API key. Create a free DeepL API account at [deepl.com](https://www.deepl.com/pro-api), then paste the key into Pepitas › Settings. Free keys end in ":fx". Without a key, you can type the Portuguese yourself.

**I can't hear the Portuguese.**
Pepitas uses the European Portuguese voice built into iOS. If no sound plays, check that your phone isn't muted, then add the voice in Settings › Accessibility › Spoken Content › Voices › Portuguese (Portugal).

**Where are my cards stored?**
Your cards are stored only on your iPhone. See the [Privacy Policy](privacy).
